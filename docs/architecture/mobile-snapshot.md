# Mobile Snapshot Architecture

## Purpose

Mobile Snapshot is the compact memory pack carried on phone so Cyro can be useful offline and away from the desktop.

## Contents

- profile summary
- active projects
- active entities
- relationship slice
- recent decisions
- preferred styles
- provider prompt preferences
- checksum/version

## Exclusions

- no full history
- no raw vault
- no full provider imports
- no full PageIndex/EvidenceTree

## Generation

Desktop compiler generates full snapshots later. MVP can create mocked/local snapshots.

## Sync

Phone captures events. Desktop compiles and sends compact snapshot back.
