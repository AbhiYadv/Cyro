# No Scraping / No Session Mirroring

Permanently blocked:
- provider cookie/session capture
- provider cookie export
- provider cookie manipulation
- hidden webviews
- DOM output reading
- stream mirroring
- auto-send
- auto-login
- human-like input automation
- subscription routing
- background provider keep-alive
- CAPTCHA bypass
- rate-limit bypass
- provider terms bypass
- stealth automation

Safe alternatives:
- manual prompt handoff
- isolated, user-visible provider sessions later
- unified composer route selector later
- user-triggered import
- Prompt Privacy Filter before provider send
- Local Only fallback for sensitive prompts
- official APIs only in separately authorized future API mode
- official OAuth
- official MCP/tools
